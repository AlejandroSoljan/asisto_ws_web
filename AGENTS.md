# Publicación de versiones del agente

- Antes de publicar una nueva versión o crear su tag, actualizar `HISTORIAL_CAMBIOS_4.04.txt` con el cambio funcional real, el impacto por dominio y cualquier corrección o reversión de una versión anterior.
- No presentar un tag o el valor `release_tag` de Mongo como prueba de que el agente ya corre en una PC. Verificar la versión reportada por la instalación.
- Conservan vigencia también las instrucciones del `C:\Asisto\AGENTS.md` superior para datos productivos.
